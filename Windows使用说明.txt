纸间 · Windows 完全离线 EPUB 阅读器
===================================

【打开方法】
1. 把压缩包解压到一个固定文件夹，例如 D:\纸间阅读器。
2. 双击「纸间阅读器.html」。
3. 如果打开成了文本，右键这个文件 → 打开方式 → Microsoft Edge 或 Google Chrome。
4. 点击「导入书籍」选择 .epub 文件，也可以直接拖入文件。

不需要安装 Python，不需要命令行，不需要启动服务，也不需要联网。
Windows 10 / 11 上较新版本的 Edge 或 Chrome 即可。
首次使用可导入压缩包中的示例书体验。

【功能】
• 目录：章节选择、目录查找、上一章 / 下一章。
• 配色：纸色、明亮、青苔、夜间，也能自己选择文字和背景颜色。
• 排版：字体、字号、行距和正文宽度。
• 书签：点击顶栏的书签图标，添加备注；在左侧「书签」中跳转或删除。
• 自动续读：关闭后重新打开同一个 HTML 文件，继续上次的位置。
• 书架：书籍保存在当前浏览器的本地存储中。
• 专注模式：隐藏侧栏，让正文有更大的阅读空间。

快捷键：← → 切换章节，B 添加书签，F 专注阅读，Esc 退出。

【记录备份】
左下角向上箭头按钮可导出阅读记录 JSON。
书架底部「导入阅读记录」可合并书签和较新的进度。
阅读记录不包含书籍正文，原始 EPUB 文件也请保留。

为了下次直接看到书架和记录，请使用同一个浏览器、同一个 HTML 文件路径。
移动或重命名 HTML、换浏览器、使用隐私模式、清除浏览器数据，可能导致原记录不可见。
迁移时，重新导入相同 EPUB，再导入备份 JSON 即可。
浏览器若无法长期保存书籍，会显示提示，本次仍可阅读。

【支持范围】
支持无 DRM 的 EPUB 2 / 3，单本最大 100 MB。
适合小说、散文、教材等文字型电子书；复杂固定版式、竖排、交互式内容不保证还原原版排版。
本工具不会执行书里的脚本，也不会加载网络图片或打开外部链接。
不支持受 DRM 加密保护的正文；部分特殊内嵌字体会使用系统字体代替。
若提示浏览器不支持解压，请使用支持 DecompressionStream deflate-raw 的新版 Edge / Chrome。
