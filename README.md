# 纸间 · EPUB 阅读器

一个安静的电子书阅读网页。**手机 / 多设备访问**可运行网页端口服务；**Windows 单机使用**可选择单文件离线版。两个版本都不使用 CDN。

## 手机网页服务

```bash
cd /root/epub-reader
bash scripts/start-web.sh
```

手机打开 **http://服务器IP:8765**。支持手机上传 EPUB、触控滚动、抽屉目录、底部阅读设置、夜间配色和专注阅读，并适配安全区与横竖屏。电脑上传的书会出现在同一个服务书架；书签与进度按各自浏览器保存。

启动脚本同时扫描 `/root/Bookshelf` 中的 EPUB。放入新书后点击网页「刷新书架」即可选读，原文件保留不动。各设备共用书籍，但阅读记录与外观设置彼此独立。

后台启动、端口设置与手机操作见 [手机网页服务说明](MOBILE-WEB.md)。网页服务没有账户验证，能访问端口的人可查看共用书架。

## Windows：双击即可使用

1. 将 `纸间阅读器-Windows离线版.zip` 复制到 Windows，解压到固定文件夹。
2. 双击 **`纸间阅读器.html`**，用较新版本的 **Microsoft Edge 或 Google Chrome** 打开。
3. 点击「导入书籍」，或将 `.epub` 文件拖入网页。

也可以只复制 `纸间阅读器.html`，它已内嵌所有程序和样式。压缩包额外提供使用说明和一本原创示例书。

离线版在浏览器中读取和解压 EPUB，书籍保存在本地 IndexedDB，书签、进度和设置保存在 localStorage。**请保持 HTML 文件路径和浏览器不变，并保留原 EPUB 文件。** 换浏览器、移动或重命名 HTML、清除站点数据，可能让原记录不可见。迁移时重新导入相同 EPUB，再导入阅读记录备份。

左下角向上箭头可导出阅读记录 JSON，书架底部可导入记录；备份不含书籍正文。浏览器不能持久化存储时会提示，仍可临时阅读。

## 可选：Python 本地服务版

这一版本保留给希望将书籍直接存放在文件夹中的用户，**Windows 单文件版不需要这些操作**。需要 Python 3.10 或更新版本，无第三方依赖。

```bash
cd /User/user/epub-reader
python3 server.py
```

浏览器打开 **http://127.0.0.1:8765**，点击「导入书籍」，或将 `.epub` 文件拖入网页。可以同时选择多本书。下次启动同一目录下的服务，书架里的书仍然保留。

如果希望自动打开浏览器：`python3 server.py --open`。停止服务按 `Ctrl+C`。

## 已有功能

- EPUB 2 / 3：读取书名、作者、嵌套目录、章节、图片和本地样式，支持中文路径和目录锚点。
- 本地书架：批量导入、相同文件自动去重，单本最大 100 MB。
- 章节选择：目录查找、上一章 / 下一章、正文内部链接跳转。
- 阅读设置：纸色、明亮、青苔、夜间四种配色；自定义背景和文字颜色；字号、行距、正文宽度、字体选择。
- 自动续读：按书籍分别保存章节、段落位置及滚动进度，重新打开时恢复。
- 书签：保存当前位置、添加备注、跳转和删除。
- 记录备份：左下角向上箭头导出 JSON；书架底部「导入阅读记录」合并书签和较新的进度。
- 专注模式、侧栏收起、手机窄屏布局。

阅读时按 `←` / `→` 切换章节，`B` 添加书签，`F` 切换专注模式，`Esc` 退出专注模式或关闭面板。用鼠标滚轮、触屏或浏览器正常滚动操作阅读章节。底部滑块可以跳到本章任意比例位置。「全书约」按章节等权计算，是大致进度，并非 EPUB 原书页码。

## Python 版的数据和运行参数

书籍和解析后的目录默认保存在项目的 `data/` 下。运行时可指定：

```bash
python3 server.py --port 8766 --data-dir /你的书籍目录
```

**书签、进度和外观设置保存在当前浏览器的 localStorage 中**，按书籍内容的 SHA-256 标识关联。清除站点数据、使用隐私窗口、换浏览器或改变访问地址 / 端口，都可能让原来的阅读记录不可见；请用「导出阅读记录」备份。导出的 JSON 不含书籍正文，完整迁移时也请复制 `data/`，或在新环境重新导入相同 EPUB。

默认仅监听 `127.0.0.1`。如果 Python 在远程服务器上运行，可在你的电脑上做 SSH 端口转发，再用本机浏览器打开：

```bash
ssh -L 8765:127.0.0.1:8765 用户名@服务器地址
```

同一可信局域网中可使用 `python3 server.py --host 0.0.0.0`，再访问 `http://服务器IP:8765`。这是个人阅读工具，没有账户或登录权限管理，书架会对能访问此端口的人可见，不适合直接暴露到公网。阅读记录按各自浏览器保存，不会自动跨设备同步。

## 支持范围

适用于无 DRM 的文字型 EPUB。受 DRM 保护的正文会提示无法读取。为让配色和字号生效，正文使用可滚动的统一排版；固定版式漫画、复杂多栏、竖排和交互式 EPUB 不保证还原原版布局。书籍脚本和外部网络资源会被禁用，内嵌图片和样式仍可加载。IDPF 字体混淆暂不解码，遇到此类字体会使用系统字体。

## 验证与示例书

离线版已在当前 Linux 环境的 Firefox 140 中以 `file://` 方式通过 26 项浏览器检查，包括 EPUB 2 / 3、内嵌图片、书签备注、配色和字号、快速切书、备份合并、真正刷新后的 IndexedDB 书架和阅读位置恢复，并确认没有 HTTP / HTTPS 资源请求。尚未在 Windows 的 Edge / Chrome 上实机测试。

重新生成单文件和 Windows 压缩包：`python3 build_offline.py`。这一步仅供修改源码后的开发者使用，最终用户直接打开 HTML 即可。离线浏览器测试脚本为 `tests/offline-smoke.js`，`python3 tests/prepare_browser_test.py` 可生成含内嵌测试书的测试页面。

以下命令检查可选 Python 服务版：

```bash
python3 -m unittest discover -s tests -v
```

测试覆盖 EPUB 2 / 3、嵌套目录、中文文件名、无目录回退、损坏 / 加密文件、路径校验、重复导入、HTTP 上传、资源读取和内容隔离。

生成不含版权素材的示例书，再从网页导入：

```bash
python3 make_demo.py
```

会生成 `examples/在纸页之间.epub`，可以体验三章正文、嵌套目录、插图和书签。
